# 高精度 AI競馬的中予想システム (Precision Horse Racing AI)

機械学習（LightGBM / Random Forest）と期待値（EV）算出アルゴリズムを統合した競馬的中予想アプリケーションです。

## 主な機能

1. **AI勝率・複勝率予測**
   - 過去走スピード指数、騎手/調教師勝率、斤量、馬場適性などの多角的なデータから勝ち馬確率および複勝確率を算出します。

2. **期待値（EV）に基づく推奨買い目生成**
   - 単勝 (Win)、複勝 (Place)、馬単 (Exacta)、3連複 (Trio) の期待値を自動計算し、収益性の高い買い目を自動提案します。

3. **レースごとの予測検証 → フィードバック学習（精度向上ループ）**
   - 予想を表示した時点の予測を「事前予測スナップショット」として保存（結果入力後は凍結）。
   - 結果入力時に事前予測と実際の着順を照合し、外れ方（本命の過大評価・1番人気の軽視・穴馬の見逃し・波乱など）と、◎と勝ち馬の差から「過信した要因／軽視した要因」を自動診断。
   - 検証済みレースから2段目の補正モデル（AI確率・オッズ確率・各要因の重み）を学習。交差検証で生モデルより誤差が小さい場合のみ採用。
   - ベースモデルは外したレースほど重く再学習し、直近レースで悪化しない場合のみ採用（検証済み8レース以上で実施）。
   - 的中率・回収率・対数損失は全て事前予測で集計（結果を学習した後のモデルで再採点しない）。

4. **直感的なWeb UI & インタラクティブ操作**
   - サンプルG1レース（ジャパンカップ、有馬記念など）の切り替え。
   - 出走馬データの手動追加・条件調整機能。
   - ワンクリックでのAIモデル再学習機能。

```
├── app.py                 # Flask API サーバー
├── src/
│   ├── models.py          # レース・馬データモデル定義
│   ├── data.py            # データ抽出・特徴量生成・シミュレーションデータ作成

├── templates/
│   └── index.html         # メイン画面テンプレート
```

## 起動方法

### 1. 依存ライブラリのインストール
```bash
pip install pandas numpy scikit-learn lightgbm flask pytest
```

### 2. アプリケーションの起動
```bash
python3 app.py
```
ブラウザで `http://localhost:5000` にアクセスします。

### 3. レース結果のフィードバック手順
1. レース前にレースを選択して予想を表示（事前予測が保存される）
2. レース後「レース結果入力・学習」から1〜3着と単勝払戻を入力
3. 「予測検証 ＆ フィードバック学習レポート」に検証結果と次回予想への反映内容が表示される

API: `POST /api/feedback/record_result` / `GET /api/feedback/review/<race_id>` / `GET /api/feedback/report`

### 4. テストの実行
```bash
PYTHONPATH=. pytest -v
```
