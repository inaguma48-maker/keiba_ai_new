# NotebookLM 資料パック：資金30倍計画

## 目的
「競馬で資金を30倍にする」計画を NotebookLM 上で組み立て、数字で検証するための資料一式。

## NotebookLM への入れ方
1. NotebookLM で新しいノートブックを作る
2. 「ソースを追加」→「ウェブサイト」に下記URLを貼り付ける(1件ずつ。リポジトリは公開設定)
   - 取り込めない場合は、各ファイルの本文を「コピーしたテキスト」で貼り付ける

```
https://raw.githubusercontent.com/inaguma48-maker/keiba_ai_new/claude/adoring-johnson-vt8v9l/docs/notebooklm/01_%E5%89%8D%E6%8F%90%E3%81%A8%E6%95%B0%E5%AD%A6.md
https://raw.githubusercontent.com/inaguma48-maker/keiba_ai_new/claude/adoring-johnson-vt8v9l/docs/notebooklm/02_30%E5%80%8D%E5%88%B0%E9%81%94%E3%82%B7%E3%83%9F%E3%83%A5%E3%83%AC%E3%83%BC%E3%82%B7%E3%83%A7%E3%83%B3.md
https://raw.githubusercontent.com/inaguma48-maker/keiba_ai_new/claude/adoring-johnson-vt8v9l/docs/notebooklm/03_30%E5%80%8D%E8%A8%88%E7%94%BB_%E6%89%8B%E9%A0%86.md
https://raw.githubusercontent.com/inaguma48-maker/keiba_ai_new/claude/adoring-johnson-vt8v9l/docs/notebooklm/04_%E6%9C%AC%E3%82%A2%E3%83%97%E3%83%AA%E3%81%AE%E4%BA%88%E6%83%B3%E3%83%AD%E3%82%B8%E3%83%83%E3%82%AF%E3%81%A8%E9%99%90%E7%95%8C.md
```

3. 必要に応じて自分の馬券購入履歴(CSV/スプレッドシート)も追加する
4. `05_質問プロンプト集.md` の質問を順にチャットへ貼る

## ファイル一覧
| ファイル | 内容 |
|---|---|
| 01_前提と数学.md | 払戻率・期待値・30倍到達確率の上限 |
| 02_30倍到達シミュレーション.md | `tools/sim_30x.py` の結果と読み方 |
| 03_30倍計画_手順.md | 実行手順・資金管理・撤退ライン |
| 04_本アプリの予想ロジックと限界.md | keiba_ai_new の仕組みと未検証点 |
| 05_質問プロンプト集.md | NotebookLM に投げる質問 |

## 注意
- NotebookLM は入れた資料の範囲で回答する。資料に無い「必勝法」は出てこない。
- 数値の再計算は `python3 tools/sim_30x.py` で行う。
