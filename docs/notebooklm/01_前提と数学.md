# 前提と数学

## JRA の払戻率(控除後に払い戻される割合)
出典: JRA 公式「馬券の払戻率」(最新値は公式で要確認)

| 券種 | 払戻率 |
|---|---|
| 単勝・複勝 | 80% |
| 枠連・馬連・ワイド | 77.5% |
| 馬単・3連複 | 75% |
| 3連単 | 72.5% |
| WIN5 | 70% |

→ 無作為に買うと、長期の期待値(EV)は 0.70〜0.80。

## 期待値(EV)
EV = 的中確率 × オッズ
- EV < 1.0: 続けるほど資金は減る
- EV = 1.0: 損得なし(ただし 30倍への到達は運次第)
- EV > 1.0: 続けるほど資金が増える(優位性がある)

## 30倍到達確率の上限(数学的事実)
EV ≤ 1.0 の賭けしかできない場合、どんな賭け方(全額・分割・転がし・マーチンゲール等)をしても、
破産前に資金30倍へ届く確率は **1/30 ≒ 3.3% 以下**。
(公正なゲームでは資金の期待値が増えないため。オプショナル停止定理)

→ 30倍を「高い確率で」達成する唯一の条件は、**EV > 1.0 の馬券を見つけ、それを大量に繰り返すこと**。
