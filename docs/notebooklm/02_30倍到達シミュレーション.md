# 30倍・300倍到達シミュレーション結果

`tools/sim_30x.py` の出力(20,000試行、乱数シード42)。破産 = 初期資金の1%未満。
- 30倍: `python3 tools/sim_30x.py`
- 300倍: `python3 tools/sim_30x.py 300 3000 10000`

| 1.100 | 3.67 | 4.03 | 4.44 |
| 1.200 | 4.00 | 4.80 | 5.76 |

読み方: 一発勝負・転がしは EV に関係なく 2〜6% 程度。**95%前後の確率で資金を失う**。

## 30倍の結論
- 30倍の現実的なルートは「EV 1.10 以上 × 2%前後の賭け × 数千回」。
- EV 1.10 でも 1000回では 3〜8%。**時間(回数)が必要**。
- EV 1.0 未満では、どれだけ回数を重ねても 0%。

## C. 毎回2%賭けで300倍に届くまでの回数の目安(資金の中央値)
| EV | オッズ3倍 | オッズ10倍 |
|---|---|---|
| 0.725 | 届かない | 届かない |
| 0.800 | 届かない | 届かない |
| 1.000 | 届かない | 届かない |
| 1.050 | 9,578回 | 届かない |
| 1.100 | 3,597回 | 25,218回 |
| 1.200 | 1,599回 | 2,738回 |

## 300倍の結論
- 必要な条件は30倍と同じ「EV 1.10 以上」。違いは回数で、オッズ3倍・2%賭けなら中央値で約3,600回(30倍は約2,100回)。
- EV 1.10・オッズ3倍なら、最大10,000回で 99.98%、最大3,000回では 31.77%。
- 高オッズの馬券は2%でも賭けすぎになりやすい。EV1.05・オッズ10倍は最大10,000回で 6.46%、表Cでは資金の中央値が届かない(01 のケリー基準を参照)。
- EV 1.0 以下では、どの賭け方でも最大 0.33%(= 1/300)。一発勝負・転がしは 0.13〜0.58%。

## 表の読み方の注意
- 表Cは資金の「中央値」の目安。オッズが高いほどばらつきが大きく、中央値より早く届く人もいる。期限内に届く確率は表Bを見る。
- シミュレーションは「EVとオッズが毎回同じ」「自分の賭け金でオッズが変わらない」「税金なし」を仮定している(03 の実運用の制約を参照)。
