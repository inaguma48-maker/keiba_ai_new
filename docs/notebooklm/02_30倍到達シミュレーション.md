# 30倍到達シミュレーション結果

`python3 tools/sim_30x.py` の出力(20,000試行、乱数シード42)。
破産 = 初期資金の1%未満。

## A. 一発勝負 / 転がし(到達確率 %)
| EV | 30倍1点 | 2段転がし(約5.5倍x2) | 3段転がし(約3.1倍x3) |
|---|---|---|---|
| 0.725 | 2.42 | 1.75 | 1.27 |
| 0.800 | 2.67 | 2.13 | 1.71 |
| 1.000 | 3.33 | 3.33 | 3.33 |
| 1.050 | 3.50 | 3.68 | 3.86 |
| 1.100 | 3.67 | 4.03 | 4.44 |
| 1.200 | 4.00 | 4.80 | 5.76 |

読み方: 一発勝負・転がしは EV に関係なく 2〜6% 程度。**95%前後の確率で資金を失う**。

## B. 繰り返し賭け(毎回 現資金の2%を賭ける・抜粋。全行はスクリプト出力を参照)
| EV | オッズ | 最大1000回 | 最大3000回 |
|---|---|---|---|
| 0.725 | 3倍 | 0.00 | 0.00 |
| 0.800 | 3倍 | 0.00 | 0.00 |
| 0.800 | 10倍 | 0.00 | 0.00 |
| 1.000 | 10倍 | 0.81 | 2.62 |
| 1.050 | 3倍 | 0.18 | 21.29 |
| 1.050 | 10倍 | 2.77 | 11.92 |
| 1.100 | 3倍 | 3.12 | 85.27 |
| 1.100 | 10倍 | 8.04 | 34.87 |
| 1.200 | 3倍 | 61.54 | 100.00 |
| 1.200 | 10倍 | 32.61 | 88.74 |

補足: 1/4ケリーで賭け率を決めた場合も、EV1.2・オッズ3倍・1000回以外は2%と同じ結果(1/4ケリーの値が下限2%を下回るため)。EV1.2・3倍・1000回のみ 1/4ケリーで 82.41%。

## 結論
- 30倍の現実的なルートは「EV 1.10 以上 × 2%前後の賭け × 数千回」。
- EV 1.10 でも 1000回では 3〜8%。**時間(回数)が必要**。
- EV 1.0 未満では、どれだけ回数を重ねても 0%。
