# keiba_ai_new の予想ロジックと限界

## 仕組み
- 勝率予測: LightGBM(`src/predictor.py`)
- 複勝率予測: RandomForest(`src/predictor.py`)
- 特徴量: 年齢、馬体重、斤量、過去スピード指数、過去勝率、騎手・調教師勝率、馬場適性、オッズ、オッズからの暗黙確率、距離、頭数 など19項目
- 買い目: 単勝・複勝・馬単・3連複の EV を計算して推奨(`src/strategy.py`)
- 賭け金: 1/4ケリー相当、1レース 2%〜20%(`compute_kelly_stake`)
- 結果記録と再学習: `src/feedback_loop.py`

## 未検証点(30倍計画の前に解消が必要)
1. **学習データが合成データ**: `src/data.py` の `generate_synthetic_historical_data` で作った架空のレースで学習している。実レースでの精度は不明。
2. **複勝・馬単・3連複のオッズが概算式**: 例 複勝オッズ = 単勝オッズ × 0.28 + 1.0。実際の払戻とのズレは不明。
3. **オッズを特徴量に含む**: 市場の予想をなぞる傾向になり、市場より優れた確率(=EV>1)を出せるかは不明。
4. **賭け金上限20%**: シミュレーション上、30倍・300倍狙いでは2%前後で十分。20%は破産リスクを上げる。
5. **賭け金の下限**: ケリー基準が小さくても最低2%を推奨する。さらに単勝は EV<1 で推奨対象になった馬券でも5%、該当なしの時の本命は10%を推奨する(`src/strategy.py`)。01 のケリー基準を超える賭けになりうる。
6. **実データでの回収率**: 不明(バックテスト未実施)。
