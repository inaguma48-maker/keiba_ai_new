# NotebookLM 質問プロンプト集

順番に貼り付けて使う。回答には必ずソースの引用を確認すること。

## 1. 前提の理解
- 「資料に基づき、資金を30倍にするために必要な条件を、期待値・賭け方・回数の3点で説明して」
- 「一発勝負と繰り返し賭けで、30倍到達確率がどう違うかを表で比較して」

## 2. 計画の具体化
- 「初期資金を【要記入】円とした場合、03_30倍計画_手順 に沿った月ごとの行動計画を作って。数値は資料にあるものだけ使い、無いものは『不明』と書いて」
- 「1年間に自分が買えるレース数を【要記入】とした場合、シミュレーションBのどの行に近いか、到達確率の目安を答えて」

## 3. リスクの洗い出し
- 「この計画が失敗する原因を、資料から挙げて優先度順に並べて」
- 「04_本アプリの予想ロジックと限界 の未検証点を、解消の順番とともに整理して」

## 4. 実績の評価(購入履歴を追加した後)
- 「追加した購入履歴から、券種別の回収率と的中率を計算して。合格条件(回収率110%以上・1000レース以上)を満たしているか判定して」
- 「回収率が高い条件(券種・オッズ帯・競馬場)と低い条件を比較して」

## 5. 判断
- 「現時点の資料だけで、フェーズ3(本番運用)に進んでよいか。進めない場合、何が足りないか」
